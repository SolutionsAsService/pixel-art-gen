Stack

PIXELGEN is the stack's placeholder-art and prototyping tool. It has no dependencies and no server, so it runs in a browser, in a build script or in CI.

Use it from a build

node _src/render.mjs --kind hero --bits 16 --palette snes --seed ember-3 --scale 8 --out hero.png

Prints one line of JSON, including a pixel fingerprint. Run it twice and the fingerprint matches. For the hero above it prints 68416de5, and the Studio shows the same pixels for hero · 16-bit · SNES · ember-3.

Atlas format

A sheet downloads as sheet.png plus sheet.json. Frames are in pixels and every frame names the seed that makes it again.

{
  "format": "shadw-pixelgen-atlas/1",
  "image": "sheet.png",
  "size": {
    "w": 68,
    "h": 34
  },
  "scale": 1,
  "frames": [
    {
      "name": "hero-ember-3",
      "x": 1,
      "y": 1,
      "w": 32,
      "h": 32,
      "kind": "hero",
      "bits": 16,
      "palette": "snes",
      "seed": "ember-3",
      "colours": 10
    },
    {
      "name": "creature-ash-1",
      "x": 35,
      "y": 1,
      "w": 16,
      "h": 16,
      "kind": "creature",
      "bits": 8,
      "palette": "nes",
      "seed": "ash-1",
      "colours": 3
    }
  ]
}

Where it fits

  • SHADW Terrain

    Islands are small height-banded maps with a coast. A fit for test overworlds and thumbnails. Not wired in yet.

  • SHADW Game Store

    Store art for a game that has none yet: capsule icons and placeholder screenshots. Not wired in yet.

  • SHADW Modding

    An art pack for a mod: a sheet, an atlas and the seeds that rebuild it. Not wired in yet.

  • Gaming master index

    Listed there as a tool, next to the modding and forge repos.

Limits, stated

  • Sprites are 16 by 16 or 32 by 32 (islands 32 or 64). There is no animation yet.
  • Palettes are exact; console sprite counts and tile rules are not simulated.
  • The art is procedural, so it is a start for an artist, not a replacement.
